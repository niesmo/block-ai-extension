## Core Entities

### AITask

Represents a single AI generation request from task creation to completion.

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| `id` | string | Unique task identifier | UUID v4, immutable |
| `status` | TaskStatus | Current processing state | enum, transitions enforced |
| `prompt` | string | User's instruction to AI | 1-2000 chars, required |
| `context` | CodeContext | Source code and location | required |
| `result` | AIResult \| null | Generated output | null until complete |
| `error` | ErrorInfo \| null | Failure details | null unless failed |
| `createdAt` | Date | When task was created | auto-set |
| `startedAt` | Date \| null | When processing began | null until started |
| `completedAt` | Date \| null | When task finished | null until done |
| `cancellationToken` | CancellationTokenSource | For cancellation | internal |

#### State Transitions

```
           ┌──────────┐
           │  queued  │◄───── initial state
           └────┬─────┘
                │ dequeue
                ▼
           ┌──────────┐
     ┌─────│ running  │─────┐
     │     └────┬─────┘     │
     │ cancel   │ success   │ error
     ▼          ▼           ▼
┌──────────┐ ┌──────────┐ ┌──────────┐
│cancelled │ │completed │ │  failed  │
└──────────┘ └──────────┘ └──────────┘
     │            │            │
     └────────────┴────────────┘
              │ dismiss/apply
              ▼
         ┌──────────┐
         │ archived │
         └──────────┘
```

### TaskStatus (Enum)

| Value | Description |
|-------|-------------|
| `queued` | Waiting to be processed |
| `running` | Currently being processed by AI |
| `completed` | Successfully generated result |
| `failed` | Processing error occurred |
| `cancelled` | User cancelled the task |
| `archived` | Result applied or dismissed |

---

### CodeContext

The source code and location that the AI task operates on.

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| `documentUri` | string | URI of source document | valid file/untitled URI |
| `languageId` | string | Language identifier | e.g., "typescript", "python" |
| `selectedText` | string | The selected/target code | 1-50000 chars |
| `selectionRange` | Range | Start/end positions | valid range |
| `fullDocumentText` | string \| null | Optional: full file for context | truncated if >100k |
| `relativePath` | string | Workspace-relative path | for display |

#### Range (Value Object)

| Field | Type | Description |
|-------|------|-------------|
| `startLine` | number | Starting line (0-based) |
| `startCharacter` | number | Starting column (0-based) |
| `endLine` | number | Ending line (0-based) |
| `endCharacter` | number | Ending column (0-based) |

### AIResult

The output generated by the AI model.

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| `generatedCode` | string | The AI-generated code | required |
| `explanation` | string \| null | Optional explanation from AI | max 5000 chars |
| `confidence` | number \| null | Model confidence (0-1) | optional |
| `tokenCount` | TokenUsage | Tokens used | for quota tracking |
| `modelId` | string | Model that generated result | e.g., "gpt-4o" |
| `streamedAt` | Date | When streaming completed | auto-set |

#### TokenUsage (Value Object)

| Field | Type | Description |
|-------|------|-------------|
| `promptTokens` | number | Input tokens used |
| `completionTokens` | number | Output tokens generated |
| `totalTokens` | number | Sum of both |

### ErrorInfo

Details about a task failure.

| Field | Type | Description |
|-------|------|-------------|
| `code` | string | Error code (e.g., "quota_exceeded") |
| `message` | string | Human-readable message |
| `isRetryable` | boolean | Whether retry might succeed |
| `details` | object \| null | Additional error context |

#### Common Error Codes

| Code | Description | Retryable |
|------|-------------|-----------|
| `model_unavailable` | Copilot model not accessible | Yes |
| `consent_required` | User hasn't granted consent | Yes (after consent) |
| `quota_exceeded` | Rate limit or quota hit | Yes (after cooldown) |
| `context_too_large` | Input exceeds token limit | No |
| `network_error` | Connection failed | Yes |
| `generation_failed` | Model returned error | Sometimes |
| `cancelled` | User cancelled | No |

---

### TaskQueue

In-memory collection managing the ordered list of tasks.

| Operation | Description |
|-----------|-------------|
| `enqueue(task)` | Add task to end of queue |
| `dequeue()` | Get next task for processing |
| `cancel(taskId)` | Cancel specific task |
| `getAll()` | List all tasks |
| `getByStatus(status)` | Filter by status |
| `clear()` | Remove all tasks |

#### Queue Invariants
- Maximum 10 tasks in queue at once
- Only 1-3 tasks running concurrently (configurable)
- Completed/failed tasks retained for 30 minutes
- Archived tasks removed from memory

| Field | Type | Default | Scope | Description |
|-------|------|---------|-------|-------------|

| `notificationStyle` | enum | "toast" | User | How to notify completion |
| `contextFiles` | string[] | [] | Workspace | Additional context files |

## Persistence Strategy

| Entity | Storage | Lifecycle |
|--------|---------|-----------|
| TaskQueue | Memory (Map) | Extension lifetime |
| Active Tasks | Memory | Until archived |
| Completed Tasks | globalState | Survives restart (limited) |
| Configuration | VS Code settings + workspace file | Persistent |
| Results | Memory + temp virtual docs | Until applied/dismissed |

### Recovery on Restart
- Queued tasks with status `running` restored as `queued`
- Completed tasks with unapplied results restored
- Failed/cancelled/archived tasks not restored

---

## Validation Rules

### AITask Creation
1. Prompt must be 1-2000 characters
2. CodeContext must have valid documentUri
3. Selected text must be non-empty
4. Cannot create if queue is full

### Status Transitions
1. Only `queued` → `running` (via dequeue)
2. Only `running` → `completed` | `failed` | `cancelled`
3. Terminal states cannot transition (except to archived)

### Result Application
1. Result can only be applied if task status is `completed`
2. Document must still exist
3. Target range should be validated (warning if changed)
